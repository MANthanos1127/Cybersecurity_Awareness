🛡️ CyberShield - Cyber Security Awareness Platform

CyberShield is a lightweight, responsive, and interactive web application designed to educate users about common cyber threats, online safety practices, and emergency resources for cybercrime victims.


 🌟 Key Features

* Informative Content: Explains fundamental cybersecurity concepts clearly.
* Top 10 Cyber Threats: Outlines prevalent scams including Phishing, UPI fraud, Remote Access exploits, and Sextortion.
* Actionable Safety Tips: Simple, essential rules for staying safe online.
* Emergency Help Directives:Direct links to official reporting portals (e.g., [cybercrime.gov.in](https://cybercrime.gov.in)) and national helpline details (**1930**).
* Dynamic Interactivity: Built-in JavaScript features including:
  * Smooth scrolling navigation.
  * Active section tracking in the header.
  * Scroll-triggered list reveal animations.
